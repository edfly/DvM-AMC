## 二、P0 关键发现：eq:main_correction 与 Theorem 2 的校正因子**倒置**

### 2.1 从第一性原理重推（共形度量 `g=λ²I`）

设状态转移 `φ: p(t)→p(t+1)`。对函数 `f=ℒ∘φ`，其**黎曼梯度**沿 `φ` 的拉回为

```
∇ₜᴹ f = gₜ⁻¹ (Dφ)ᵀ gₜ₊₁ ∇ₜ₊₁ᴹ
       = (1/λₜ²)(Dφ)ᵀ·λₜ₊₁²·∇ₜ₊₁ᴹ
       = (λₜ₊₁²/λₜ²)·(Dφ)ᵀ·∇ₜ₊₁ᴹ        ……（因子 = 后/前）
```

自然梯度（Amari）对同一变换给出**同一结果**：`Gₚ⁻¹(Dφ)ᵀG_q g̃_q`，代入 `G=λ²I` 得因子 **`λ_{t+1}²/λ_t²`**。

而论文 eq:main_correction 写的是 **`λ_t²/λ_{t+1}²`（前/后）**——与标准黎曼/自然梯度拉回**互为倒数**。

### 2.2 参数梯度视角（另一种判据）

对参数 `θ`：`∂ℒ/∂θ = (Dφ)ᵀ·(∂ℒ/∂p(t+1)|ᴱ)·(∂φ/∂θ)`，其中输出的坐标梯度已自带 `g_{t+1}` 度量。两步度量相消，**正确坐标梯度不含任何 λ 因子**（即朴素 autograd 链即可）。论文却在此处硬插 `λ_t²/λ_{t+1}²`——既不是正确参数梯度（应为 1），也不是正确状态黎曼梯度（应为 `λ_{t+1}²/λ_t²`）。

### 2.3 代码与公式一致，但哨兵检验是**循环论证**

- `dvm.py:166` `PerStepMetricCorrection` 与 `dvm.py:81` `DvMFunction` 均实现因子 `(λ_old²/λ_new²)` = 论文的 `λ_t²/λ_{t+1}²`——**代码与公式相互印证**。
- 但 "M=T 哨兵验证 AMC 复现真实黎曼梯度" 的比较基准（full_BPTT_mc）**同样走该（倒置）因子**，故哨兵只验证"代码自洽"，**并不独立验证真实黎曼梯度**。这正是记忆中反复警示的盲区："只验表格↔JSON 有盲区，须查脚本计算图是否真实"——此处计算图自洽但数学方向错。

### 2.4 为何此前未被发现（诚实说明）

TU 工作点 `λ²` 动态范围仅 ≈1.016（`λ_0²/λ_T²≈1`），两种符号的因子都 ≈1，故哨兵"通过"、实验"无影响"。**误差只在 `λ_T/λ_0≫1`（高分散）时显形**，恰是论文"正区间"合成实验所触及之处——但该实验做的是 **AMC 校正 vs 未校正的相对比较**，两端用同一（倒置）约定，相对结论仍成立。

## 三、P1 推论过度："望远镜→方向余弦 1.0"

论文 §5.4 称"望远镜恒等式使 AMC 校正梯度方向**精确等于** ground truth（每格余弦 1.0），只剩 `ρ^{T−M}` 遗忘惩罚"。

- 望远镜只保证**度量部分**精确（连乘消成端点比），**并不**保证**梯度方向**相等——方向还取决于被截断的 Jacobian 乘积 `J_0…J_{T−M−1}`。
- 余弦=1.0 仅在"被遗忘的 Jacobian 在相关方向上为标量"时成立。该文合成链是**径向后测扫掠**（沿径向、转移为标量倍），故在其构造下成立，但被陈述为望远镜的普遍推论——属**过度泛化**。建议在文中注明"该结论针对径向后测合成链，非一般定理"。

## 四、鲁棒性分析：哪些结论在符号错误下仍然成立

| 论文结论 | 是否受符号错误影响 | 原因 |
|---|---|---|
| §5.4 TU 工作点校正≈恒等（中位 `\|Δcos\|≈10⁻⁶`） | 否（鲁棒） | `λ_0≈λ_T` 时 `λ_0²/λ_T²≈1` 与 `λ_T²/λ_0²≈1` 同趋于 1 |
| "正区间"：高分散下未校正梯度发散、AMC 提供分散无关误差上限 | 否（鲁棒） | AMC vs 未校正均为**同约定相对比较**；度量部分望远镜精确→误差仅剩遗忘项 `1−ρ^{T−M}`，符号无关 |
| 误差界 `ε≤C(1−ρ^{T−M})` 作为**界** | 否（成立） | 几何级数界对 Jacobian 截断有效；度量比有界则由稳定性投影保证 |
| "AMC 精确复现黎曼梯度"（M=T 哨兵表述） | **是（过度宣称）** | 哨兵循环；绝对梯度差一个端点比 |
| eq:main_correction 作为显式公式 | **是（数学错误）** | 因子倒置 |

## 五、从数学角度定位：本论文解决的是哪个方向的**优化 / 稳定 / 区间 / 创新**

### 优化（Optimization）方向 —— **内存-精度 Pareto 优化，而非精度优化**
- 论文已自我重定向：引言"刻画权衡而非声称精度胜出"；校正量在 TU 甚至略有害（MUTAG −6.6pt, p=0.011）。
- 真正优化对象是**反向传播的内存复杂度**：`O(Td)→O(Md)`，代价是梯度误差 `≤C(1−ρ^{T−M})`。对应其 "Energy–Accuracy Pareto" 章节。
- 与 Amari 自然梯度的关联是**文献定位**（优化在流形上），但方法本身不是新优化器，而是**截断 BPTT 的度量校正算子**。

### 稳定（Stability）方向 —— **收缩假设 + 度量有界性 双稳**
- 误差界依赖**收缩假设** `‖Dφ‖≤ρ<1`（取 `ρ=0.9`=LIF 膜衰减）。这是动力学稳定性假设，论文已诚实标注"未精确计算耦合谱范数"。
- 数值稳定性由**投影** `‖x‖≤1/√c−ε` 保证 `λ` 有界 → 误差常数 `C` 与 T **无关**（Corollary 1：`T→∞` 误差收敛到有限极限，不发散）。
- 结论：论文确有稳定性结果，但**取决于未严格验证的收缩性**。

### 区间（Interval）方向 —— **误差区间 + 校正正区间**
- **误差区间**：`ε∈[0, C]`，随 `T→∞` 收敛到有限上界（非膨胀）——这是"截断不会因为序列变长而失稳"的区间保证。
- **校正正区间**：校正增益 = `|k−1|`，`k=λ_{T−M}²/λ_T²`（窗口端点共形偏离）。论文核心创新定位即：**增益由端点偏离决定、在 TU 可忽略**，并给出"正区间"（高分散 `λ_T/λ_0≳2` 处不可或缺、恒等附近近无影响）。这是围绕 `k=1` 邻域的**区间分析**。

### 创新（Innovation）方向 —— **望远镜恒等式（真实贡献）**
- **真创新点**：逐步共形校正沿任意窗口连乘**精确消成端点比** `λ_a²/λ_b²`，与中间轨迹、曲率 `c`、`λ` 动态范围**均无关**。这一代数事实使：
  1. 截断 BPTT 中度量重锚定**零额外误差**（Δ_r=0）；
  2. 误差界可闭式写出；
  3. 识别出"增益由端点偏离决定而非曲率"——推翻了早期"随曲率单调"的错误 claim（Spearman 0.075→0.939 重设计）。
- 第二大贡献是**诚实实证重构**（撤回 46pp 主张、TU 零结果、定位正区间），符合学术诚信纪律。
- **但**：创新所依赖的显式公式 eq:main_correction 符号倒置，且"精确复现黎曼梯度"属循环验证。**应在公式层面纠正或明确重述为"相对一致的校正算子"**。

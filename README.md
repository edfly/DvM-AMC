# DvM-AMC

**Differentiation-via-Manifold: Analytic Metric Correction (AMC)** — memory-efficient
gradient computation on Riemannian manifolds for spiking neural networks.

This repository accompanies the manuscript *"Differentiation-via-Manifold: Memory-Efficient
Gradient Computation on Riemannian Manifolds for Spiking Networks"*. It contains the full
source code, the categorized experimental artifacts, and a machine-verification suite that
re-checks every reported number against its JSON source. (The anonymized LaTeX source and
compiled PDF are kept in the author's local checkout only — see the double-blind note
below.)

> **Double-blind note.** Author identity is withheld in the manuscript; repository URLs that
> appear in the paper use the `Anonymous` placeholder and will be replaced with the real
> link upon acceptance.

> **Manuscript not in the published repository.** The anonymized LaTeX source
> (`paper/`, cas-dc / Elsevier) and the compiled PDF live only in the author's local
> checkout. They are intentionally **excluded from the published repository** to protect the
> double-blind submission and can be re-added after acceptance. The machine-verification
> suite detects a missing manuscript and automatically skips the table→JSON traceability
> check (the data-JSON consistency checks still run); `check_all.sh --compile` likewise
> skips PDF rebuild when `paper/` is absent.

## Repository structure

```
DvM-AMC/
├── code/
│   ├── spikergnn/        # the `spikergnn` package (manifold-valued LIF, Riemannian GNN,
│   │                     #   DvM metric-correction / truncated BPTT, ablations)
│   ├── msg_baseline/     # MSG few-shot baseline (sibling package)
│   ├── scripts/          # training / experiment / analysis entry-point scripts
│   └── verify_suite/     # four-fold machine-verification suite (7 checks)
├── data/                 # categorized experimental artifacts (JSON only; no raw datasets)
│   ├── final_results_*.json     # per-dataset main results (n=9)
│   ├── rerun_outputs/           # No-Spikes / OM ablation runs
│   ├── gnn_baselines/           # GNN baseline results (SGC/GIN/GCN/SAGE/SGC)
│   ├── ablations/               # long-horizon trade-off, four-stage MSG comparison
│   ├── arxiv_validation/        # ogbn-arxiv positive-interval validation
│   ├── curvature_sweep/         # curvature / endpoint-deviation sweeps
│   ├── gradient_diagnostics/    # gradient-fidelity diagnostics
│   ├── msg_baseline/            # MSG baseline result JSONs
│   ├── stats/                   # bootstrap significance / provenance
│   ├── T_sweep/                 # memory (O(M)) sweep results
│   ├── complete_results.json    # consolidated matrix
│   └── bootstrap_stats.json     # bootstrap CIs (generated by verify_suite)
├── LICENSE               # MIT
└── README.md
```

Raw datasets (TUDatasets MUTAG/PROTEINS/NCI1/DD, ogbn-arxiv) are **not** included
(license + size); only the exported result JSONs live under `data/`.

## Machine verification

Every reported number in the paper is traced to its JSON artifact by the verification
suite. **Run this after any change to code or data:**

```bash
cd code/verify_suite
bash check_all.sh            # 7 checks (no PDF compile)
bash check_all.sh --compile  # also rebuild the PDF (requires TeX Live 2026 + local paper/)
```

Exit code `0` = all green. **RULE:** when a check fails, fix the *data or the code*, never
the verification script.

The seven checks are: `audit_data`, `verify_numbers`, `verify_hyperparams`,
`verify_algorithm_mapping`, `verify_p0b`, `bootstrap_stats`, `verify_ablation_functional`.
`verify_numbers` parses the manuscript tables; when `paper/` is not present in the checkout
it prints a `[skip]` notice and still verifies that every cited source JSON exists.

## Reproducing the PDF (local only)

Requires TeX Live 2026 (cas-dc class) and the local `paper/` directory (not part of the
published repo). From the repository root:

```bash
pdflatex -interaction=nonstopmode -output-directory=paper paper/DvM_Paper_Anonymous.tex
pdflatex -interaction=nonstopmode -output-directory=paper paper/DvM_Paper_Anonymous.tex
```

## Data provenance (local only)

`paper/provenance_table.tex` records, for each reported figure, the source JSON file under
`data/` (auto-generated by `code/scripts/make_provenance_table.py`). This file lives in the
local `paper/` directory and is not part of the published repository.
